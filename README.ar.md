# Life OS 4

نسخة مطوّرة من مشروع LifeOS الأصلي، بنفس تقنيات HTML / CSS / JavaScript وPWA، مع Focus وTime Tracking وPomodoro.

## التشغيل

يتطلب Node.js 20 أو أحدث. لا توجد حزم خارجية لتثبيتها.

```powershell
npm start
```

افتح http://127.0.0.1:4173. أنشئ حسابًا محليًا أو سجّل الدخول إلى حساب موجود على نفس عنوان الموقع والمتصفح.

```powershell
npm run lint
npm test
npm run build
```

ينسخ build ملفات النشر الثابتة إلى `dist/`. يمكن تقديم هذه الملفات على الاستضافة الثابتة الحالية. لم تُنشر هذه النسخة تلقائيًا إلى Vercel.

## المزايا

- لوحة رئيسية بأولويات اليوم والعمل العميق والمهام والعادات والجدول والمشاريع.
- Stopwatch وCountdown وPomodoro قابل للتخصيص، مع Pause / Resume وملخص قبل الحفظ.
- استرجاع الجلسة بعد التحديث؛ حساب الوقت من timestamps، مع استبعاد التوقفات والاستراحات.
- فترات قصيرة وطويلة، والتحكم في بدء الراحة والتركيز التالي تلقائيًا.
- ربط جلسات الوقت بالمشروع والهدف والمهمة والتصنيف، وإدخال يدوي يمنع التداخل.
- ملاحظات جلسة، مشتتات تُحفظ في الوارد، تقييم الطاقة والتركيز ومدة دقيقة بالثواني.
- تقارير يومية وأسبوعية وشهرية، وقت المشاريع والأهداف والمهام، أهداف العمل العميق ومؤشرات الأداء.
- مشاريع وأهداف ومهام قابلة للتعديل، أولويات وحالات وتواريخ وتقديرات ووسوم ومهام فرعية وتكرار.
- تقويم يوم/أسبوع/شهر، أحداث واجتماعات وعادات، تخطيط ومراجعة يومية وأسبوعية وشهرية وربع سنوية.
- ملاحظات بحفظ تلقائي، Inbox قابل للتحويل، سجلات للمال والصحة والتعلم والقراءة.
- عربي RTL وإنجليزي LTR، مظهر فاتح وداكن وتلقائي، قائمة أقسام للهاتف.
- بحث وأوامر سريعة: Ctrl/Cmd+K، F للتركيز، T للمهمة، N للملاحظة، Space لإيقاف/استئناف التركيز. تُعطّل الاختصارات النصية أثناء الكتابة.
- الإبقاء على خريطة الزخم وخطة الأهداف والإشارات والحساب والتصدير والاستيراد الأصليين.

## البنية

- `core.js`: نموذج البيانات، ترقية الإصدار، التخزين، آلة حالات المؤقت، التقارير، إكمال المهام والتحقق من الاستيراد. يعمل مستقلاً عن DOM ويمكن اختباره في Node.
- `workspace.js`: صفحات مساحة العمل، عناصر العرض، النماذج، البحث، الحفظ التلقائي، تنسيق تحديثات التبويبات.
- `executive.css`: tokens والتصميم الجديد وRTL والتجاوب والمظهرين.
- `app.js`: التطبيق الأصلي مع إصلاحات الحفظ واللغة والربط الآمن بالواجهة الجديدة.
- `index.html` و`styles.css`: الهيكل والوظائف الأصلية؛ لم تُحذف الأقسام القديمة.
- `sw.js`: تخزين ملفات التطبيق للعمل دون اتصال، ضمن نطاق LifeOS فقط.
- `tests/`: اختبارات نموذج البيانات والمؤقت والتوافق مع الكود القديم.
- `scripts/`: تشغيل محلي وفحص وبناء دون dependencies.

## البيانات والترقية

يبقى المفتاح الأصلي `lifeos_v11_accounts`، وكذلك `lifeos_v11_session`. ترقية `schemaVersion: 4` إضافية وتحتفظ بالحقول القديمة. لا توجد قاعدة بيانات خادم أو SQL migrations.

كل حساب يحتفظ داخل `data` بالمشاريع والجلسات والملاحظات والأحداث والعادات والوارد والتخطيط والإعدادات والسجلات الإضافية. الجلسة النشطة موجودة في `activeSession`.

الجلسات تحفظ `segments` من نوع focus أو break؛ تُحتسب التقارير من تقاطع فترات focus مع حدود اليوم/الأسبوع/الشهر المحلي. إكمال الهدف مستقل عن الوقت، ويعتمد على نسبة يحددها المستخدم أو أثر المهام.

التصدير لا يتضمن passwordHash. الاستيراد يتحقق من الملف ويحفظ نسخة استعادة محلية قبل الاستبدال ويحافظ على بيانات الدخول. تُستورد الجلسة النشطة متوقفة عند وقت التصدير. يجب إنهاء الجلسة الحالية قبل الاستيراد. الأرشفة تحفظ الوقت والارتباطات؛ يمكن استعادة العناصر القابلة للبحث عبر تعديلها وحفظها.

## حدود البنية الحالية

- الحساب محلي وتجريبي، وليس مصادقة SaaS على خادم. البيانات غير مشفرة في localStorage. لا مزامنة بين الأجهزة ولا حماية أو فوترة سحابية.
- تغيير العنوان أو المتصفح لا ينقل البيانات تلقائيًا. استخدم التصدير والاستيراد؛ نشر الملفات على نفس origin يحافظ على الوصول إلى البيانات السابقة.
- يبدأ التوقيت ويستمر بالحساب من الطوابع الزمنية؛ تعديل ساعة الجهاز نفسها قد يؤثر على القياس. تنبيهات الصوت وداخل التطبيق تظهر عندما يستطيع المتصفح العمل، ولا توقظ جهازًا نائمًا.
- إذا فُعّل البدء التلقائي لكلا الطورين، تُحتسب الدورات المجدولة حتى أثناء سكون الجهاز. أوقف الجلسة مؤقتًا إذا ابتعدت عن العمل.
- منع الجلسات المكررة بين التبويبات يستخدم Web Locks في المتصفحات الداعمة. لا يوجد تنسيق جلسات بين أجهزة مختلفة.
- المرفقات محلية، حتى 500 KB لكل ملف و3 ملفات لكل عنصر، وتخضع لسعة المتصفح. خطأ امتلاء التخزين لا يستبدل النسخة المحفوظة.
- أقسام المال والصحة والتعلم سجلات شخصية عملية؛ ليست محاسبة شركات أو أنظمة طبية أو منصات تعليم متكاملة.
- التقويم داخلي؛ لا تكامل خارجي مع Google/Outlook. أسماء الأشخاص داخل المشاريع ليست حسابات تعاون مشتركة.
- لا توجد TypeScript أو عملية transpilation في هذا الـstack؛ الفحص يستخدم parser JavaScript واختبارات Node وفحص الملفات.

راجع `QA.md` للاختبارات المنفذة وحدود التحقق.
