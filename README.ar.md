# إعداد النسخة الجديدة

1. ارفع محتويات هذا المجلد كاملة إلى مستودعك يدويًا، بما فيها scripts وauth.js وcloud-sync.js.
2. إعداد Vercel موجود في vercel.json: أمر البناء npm run build ومجلد الإخراج dist.
3. لا تعد تشغيل SQL؛ الجدول الذي أنشأته سابقًا يكفي لهذا التحديث.
4. أنشئ حسابًا من التطبيق وأكّد البريد ثم ادخل. إذا لديك حساب Supabase سابق فاختر تسجيل الدخول مباشرة. الحساب المحلي القديم يحتاج التسجيل أول مرة بنفس البريد للاحتفاظ ببياناته المحلية.
5. على جهاز آخر، سجل الدخول بنفس الحساب. الحفظ والاسترجاع تلقائيان، ولا يوجد دخول سحابي منفصل.

الجلسة الجارية تبقى على الجهاز الذي بدأت منه وتُرفع عند إنهائها. انتظر ظهور حالة الحفظ قبل الانتقال. عند وجود تعديلات متعارضة ستجد خيارات الاستعادة في الإعدادات بدل استبدال بياناتك بصمت.

للتشغيل: Node.js 24.x ثم npm ci ثم npm start. للبناء: npm run build. للاختبارات: npm test.

نجح البناء و39 اختبارًا آليًا. لم يُختبر الدخول والمزامنة على Supabase الفعلي بحساب حقيقي بعد.
