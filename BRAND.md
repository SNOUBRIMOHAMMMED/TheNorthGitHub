# Life OS — Clarity identity

The L-shaped foundation and ascending path represent direction and steady progress. The vector mark is brand-mark.svg, usable independently outside the application.

Palette: forest #355E49, sage #C9DBC5, ivory #EEF3E9. The dark theme uses #171B19 and #1E2420. Retain readable contrast; color is never the only status indicator.

Typography follows the existing system stack: Segoe UI / Inter and available Arabic system fonts. No font download or network dependency was added.

Mobile navigation prioritizes Home, Goals, Focus, Habits and Settings. Other pages remain available through Explore.

The goal strip uses recorded momentum history, with completion percentage shown separately. No predicted curve is fabricated.
