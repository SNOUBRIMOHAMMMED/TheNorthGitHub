# THE NORTH / الشمال

Native HTML, CSS and raw SVG. No React or Tailwind runtime required.
Colors: obsidian #0D0D0D, chalk #FFFFFF, orange #FF5500.
The angular N shares its right stem with a north-pointing needle.
brand-mark.svg is reusable outside the application. PNG icons use the same geometry.
Arabic uses available Noto Kufi Arabic, Noto Sans Arabic or Tahoma; fonts are not bundled.
Storage keys, routes and existing application functionality are retained.
